# App Inventor GitHub Build Test

هذا المستودع يختبر تشغيل MIT App Inventor Build Server
داخل GitHub Actions.

## الاختبار

1. افتح تبويب Actions.
2. اختر:
   Test App Inventor Build Server
3. اضغط Run workflow.
4. انتظر انتهاء العملية.

إذا ظهرت:

BuildServer test finished

بنجاح، فهذا يعني أن بيئة GitHub Actions استطاعت بناء واختبار
App Inventor Build Server.
